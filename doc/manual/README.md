# IbukiGourd 开发者手册

> 面向**使用 IbukiGourd 的模组作者**。本手册里的每个签名都取自仓库源码（MC `26.2`，Kotlin `2.4.0`）。

IbukiGourd 是一个多加载器（Fabric + NeoForge）**前置库**：它不提供玩法内容，只提供配置系统、配置界面、
像素风 UI 组件库、全局覆盖层、指令 DSL、事件总线、输入系统、文本 DSL、i18n 与一批工具。

## 通用约定

- **语言**：库与本文档都用 Kotlin；例子按 MC `26.2` 的官方映射名书写（`Minecraft`、`Screen`、`Component`…）。
- **客户端 / 服务端**：带界面的能力（配置界面、屏幕、覆盖层、Toast）都是**客户端**能力；
  配置系统与指令、事件则两端都有对应管理器 / 事件。
- **`context parameters`**：配置项构造器是 `context(group: ConfigGroup)` 的扩展函数，所以要在
  `ConfigGroup` 的作用域里调用（见 [02 配置系统](02-配置系统.md)）。这是 Kotlin 的实验特性，
  **调用方模块也要开启**对应编译参数（本库构建脚本里是 `-Xcontext-parameters`；你的项目若报
  context 相关错误就补上它）。
- **界面观感**：像素风 —— 素材是 `.aseprite`，逻辑像素按整数倍放大（`LocalSokitsuPixelScale`），
  布局密度与放大倍率必须同向变化（[08 屏幕与 UI 组件](08-屏幕与UI组件.md)）。
- **文案**：界面文案走语言键，登记进 `IGLang` 子对象（[07 文本与 i18n](07-文本与i18n.md)）。

## 活例子

- `common/src/devOnly/`：30+ 个组件测试屏（主菜单 `SokitsuTestScreen`），开发期专用、不发布。
- `common/src/devOnly/kotlin/.../test/TestConfig.kt`：把每种配置项都声明了一遍的测试配置。
- `common/src/devOnly/kotlin/.../test/configwrapper/ConfigWrapperTest.kt`：配置界面的各种包装器用法。
- 仓库自用屏幕 `mod/IbukiGourdModScreen.kt`：`ModScreen`（模组屏幕）+ 配置页的完整接线。
