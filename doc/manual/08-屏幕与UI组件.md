# 08 屏幕与 UI 组件

这章解决：**怎么写一个界面**（屏幕基座、主题、像素缩放、组件选型）。

## 1. 屏幕：`SokitsuScreen`

`SokitsuScreen` 是平台 `ComposeScreen` 的薄包装，只补两件事：**套主题** + **按窗口分辨率分档缩放**。

```kotlin
SokitsuScreen.open {                       // 构造并打开（等价于 setScreen）
    Column(Modifier.fillMaxSize(), verticalArrangement = Arrangement.Center) {
        Text("hello minecraft")
    }
}
```

```kotlin
fun SokitsuScreen.open(
    parent: Screen? = null,                    // 缺省 = 打开前的当前屏幕，关闭后回到它
    renderParentScreen: Boolean = false,       // 是否把父屏画在下面
    disableWorldRender: Boolean = ComposeScreenDefaults.disableWorldRenderByDefault,  // 停画世界
    pauseGame: Boolean = IGConfig.Gui.Screen.pauseGame,   // 是否暂停游戏（配置项缺省 false）
    closeOnEsc: Boolean = true,
    animation: ScreenAnimation = ComposeScreenDefaults.animation,   // 进出场动画（配置可改）
    exitParentOnOpen: Boolean = true,
    content: @Composable () -> Unit,
): ComposeScreen
```

- 需要"先构造、由调用方自己 `setScreen`"（如 ModMenu 的屏幕工厂）时用 `SokitsuScreen.create(...)`，参数一致。
- 返回的 `ComposeScreen` 支持运行期切 `renderParentScreen` / `disableWorldRender`。
- 父屏也是 Compose 屏幕时，平台会自动标记"可复活"，回来时不重建。

## 2. 主题与像素缩放

两颗 CompositionLocal 决定观感，**必须同向变化**：

| Local | 作用 |
|---|---|
| `LocalDensity`（Compose） | 布局尺寸：`dp` / `sp` → 屏幕像素（组件 meta 的宽高、内边距、字号都走它） |
| `LocalSokitsuPixelScale` | 精灵渲染倍率：1 素材像素 → N 屏幕像素（整数） |

`SokitsuScreenRoot` 负责把它们一起算出来：测量**窗口像素**尺寸 → 按分档策略选一档 `SokitsuScreenScale(density, pixelScale)` → 下发。

```kotlin
object SokitsuScreenDefaults {
    var threshold: IntSize       // 缺省 960×720（原版自动 GUI 缩放的分档边界）；宽高同时达到用基准档
    var baseFactor: Float        // 基准档相对主题的倍率，缺省 1f
    var compactFactor: Float     // 紧凑档，缺省 0.5f
    var resolver: SokitsuScreenScaleResolver   // 整体替换分档规则
}
```

- 窗口像素指**窗口分辨率**，与原版 `guiScale` 无关 —— "UI 显得小"的根因是物理像素密度。
- 紧凑档下 `pixelScale` 不能整除时按四舍五入取整（下限 1）；需要精确控制就替换 `resolver`。
- 自己写屏幕时不要重复包一层：**`SokitsuScreen` 已经包了**；弹层（Dialog / Popup）要从所在屏幕读
  `LocalSokitsuPixelScale`，不要自己再包一层（图层约束不是窗口分辨率，分档会偏小）。

主题：

```kotlin
SokitsuTheme(
    colorScheme = currentSokitsuColorScheme(),   // ColorScheme
    typography = SokitsuTheme.typography,
    pixelScale = SokitsuThemeMeta.pixelScale,
) { /* 你的内容 */ }
```

- **配色**：`ColorScheme` 是一组语义槽位（`ColorSchemeToken`）。组件不持有具体颜色，只声明 token，
  由 `TokenResolution` 按「调用点传参 > 组件 token 表 > 主题槽位」解析。
- **资源包覆盖**：主题 meta 文件 `assets/<命名空间>/sokitsu_meta.json`（亮/暗 section + `pixelScale` + 各组件的 `uiMeta`），
  随资源重载刷新；库内默认不提供 —— 缺失时全走内置默认值。
- **配置驱动的主题**：`SokitsuThemeOverride.scheme`（`IGConfig.Gui.Theme` 会写它；`null` = 不覆盖）。
  亮/暗由 `ThemeType`（Light/Dark/Unknown）表达，`systemTheme()` 探测系统主题，探测失败按浅色收敛。
- 换配色时可以只覆盖一层：`SokitsuTheme(colorScheme = myScheme, pixelScale = LocalSokitsuPixelScale.current) { ... }`
  —— **记得把 `pixelScale` 接回来**，否则嵌套会把分档覆盖回主题缺省值。
- `SokitsuTheme` 还顺带注入内容色（`LocalContentColor`）、字体（`Typography`）、指示器、
  文本选区配色与右键菜单呈现层（`SokitsuContextMenuRepresentation`）。

## 3. 模组屏幕：`ui/ModScreen.kt`

给自己的模组分页界面（顶栏 + 页签条 + 各页内容）：

```kotlin
val state = rememberModScreenState()
ModScreen(
    tabs = listOf(
        ModScreenTab(Literal("常规")) { GeneralPage() },
        ModScreenTab(Literal("关于")) { AboutPage() },
    ),
    state = state,
    title = { Text("Your Mod") },
    icon = { ModScreenIcon(...) },
    headerActions = { /* 顶栏右侧动作 */ },
)
```

- 两个重载：缺省顶栏（`title` / `icon` / `headerActions` 三个槽位）与**自定义顶栏**
  （`header: @Composable () -> Unit` 整个由你给）。
- `ModScreenState.selectedTab` 可从外部改（"跳到某一页"）；页数变化会自动钳制。
- `ModScreenDefaults`：`HeaderPadding` / `HeaderSpacing` / `IconSize` / `Placement` / `colors()`。

## 4. 组件清单（都配 `*Theme` token 取色）

| 分类 | 组件 |
|---|---|
| 按钮 | `Button`、`ColorButton`（底色 = 给定具体颜色）、`FlatButton`（无常驻背景的底座）、`IconButton`、`TextButton` |
| 图标 | `Icon` + `Icons`（38 个像素图标，尺寸 = 素材尺寸 × `scale`，缺省 `pixelScale`） |
| 文本与装饰 | `Text`（`String` / `AnnotatedString` / MC `Component` 三种重载）、`Divider`、`ProgressBar`、`Surface` |
| 输入 | `Switch`、`Slider` + `NumberSlider`、`TextField`、`NumberField`（滚轮整体步进；方向键 C4D 式按位步进） |
| 选择 | `RadioButton` + `RadioButtonGroup`、`Selector`（单/多选，可搜索）、`ui/colorpicker` 的 `ColorPicker` + `ColorPickButton` |
| 容器 | `Scroller`（常规 + flat 细条，`autoHide` / `autoFade`）、`TabStrip`（页签条 + 面板）、`TabRow`（等宽页签行 + 指示器）、`TableLayout` + `LazyTableLayout`（列表格，支持固定列宽 / 权重 / 钉住表头） |
| 弹窗与菜单 | `AlertDialog` + `SimpleAlertDialog`、`FlexibleDialog`（宽度随内容）、`DropdownMenu` + `DropdownMenuItem`、`SokitsuContextMenu`（文本框右键） |
| 编辑浮层 | `ui/editdialog`：`EditDialog` / `EditDialogContent` / `EditDialogContentList` / `EditDialogContentCards` / `DragHandle` / `RemoveButton` / `RemoveConfirmButton` |
| 曲线 | `ui/curve`：`BezierCurveEditor` + `BezierCurvePlot` |
| 键位 | `ui/keybind`：`KeyCodeSetButton` / `KeybindSetButton` / `KeybindSettingSetButton` / `KeybindSettingColumn` |
| 物品图标 | `ui/item/ItemIcon`（原生物品绘制 + 原版 tooltip） |
| 状态 | `UiState`：`disabled > pressed > (hover ∪ focused) > normal` |

用法要点：

- `FlatButton` / `IconButton` / `TextButton` 的内容是**可组合槽位**（`@Composable RowScope.() -> Unit`），
  文字传 i18n 文案（`MiscLang.xxx`）或直接写 `String` 都行，文字 + 图标混排也直接支持。
- `Icon` 的 `scale` 缺省是**字面量 2**（不跟随 `pixelScale`，要与像素倍率联动请显式传
  `scale = LocalSokitsuPixelScale.current`）；父级约束放不下时会降到能放下的最大整数倍率（宁可变小也不非等比拉伸），
  传 `size` 则完全接管。`tint` 缺省跟随 `LocalContentColor`。
- `Scroller` 的滚动源经 `ScrollerAdapter` 解耦（`ScrollState` / `LazyListState` / `LazyGridState`）；
  `autoHide` 无滚动空间时**完全不组合**。
- 下拉菜单锚点用 `Modifier.dropdownMenuAnchor` 捕获，面板用共享的 `BubblePanel`（与 tooltip 同源）。

## 5. 素材（像素风）

- 组件素材是 `.aseprite`，放 `assets/<命名空间>/texture/sokitsu/<atlasId>/`；
  图集定义 `assets/<命名空间>/sokitsu_atlas/<atlasId>.json`；纹理 id = 路径去掉
  `texture/sokitsu/` 前缀与 `.aseprite` 后缀（如 `icon/add`）。
- 素材着色有两个正交维度（逐图层标注）：合成策略 `tint`（`Mask` / `Multiply` / `Passthrough`）
  与颜色来源 `level`（`tone` / `shadow` / `outline` / 任意 `ColorScheme` 槽位名 / `none`）。
- 细节与坑见 [12 常见问题](12-常见问题.md)。
