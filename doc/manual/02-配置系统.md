# 02 配置系统

这章解决：**怎么声明配置项、怎么读它、什么时候被保存**。配置框架本体来自依赖库
[nebula](https://github.com/forpleuvoir)（`ConfigManager` / `Config` / `ConfigGroup` / `Codec` / `ConfigSerde`），
IbukiGourd 补上 Minecraft 相关的类型（快捷键、向量、颜色…）与"注册即托管"的处理器。

## 1. 快速开始

```kotlin
object YourModConfigs : ClientModConfigManager("your_mod_id", "config") {

    init { addConfig(Gui) }                       // 挂到根上

    object Gui : ConfigGroup("gui") {
        var title by configString("title", "Hello")           // nebula 提供的基元
        var scale by configFloat("scale", 1f, 0.5f, 2f)       // 带范围 → 界面用滑条
        val openKey by configKeybind("open_key", Keyboard.RIGHT_SHIFT)  // 本仓提供
    }
}

ClientModConfigHandler.register(YourModConfigs)   // 注册后生命周期自动托管
```

- `ClientModConfigManager(modId, name)` / `ServerModConfigManager(modId, name)`：一个 `name` 一个文件
  （客户端落在加载器给的配置目录下，见 `PlatformHelper.getConfigDir()`）。
- **配置项是属性委托**：`var x by configString(...)` 给可写项，`val x by configKeybind(...)` 给自身可变的项。
- **构造器是 `context(ConfigGroup)` 扩展**：只能在 `ConfigGroup` 内调用（见手册首页的编译参数说明）。

## 2. 配置项构造器一览

### 2.1 nebula 提供（数值 / 文本 / 集合 / 颜色 / 时长 / 枚举）

| 构造器 | 说明 |
|---|---|
| `configString(name, default)` | 字符串 |
| `configBoolean(name, default)` | 开关 |
| `configInt` / `configLong` / `configFloat` / `configDouble` | 数值，可给 `min` / `max`（界面据此用滑条 / 数字框） |
| `configDuration(name, default, min, max)` | `kotlin.time.Duration` |
| `configColor(name, default)` | 颜色（nebula `Color`，界面用取色器） |
| `configEnum(name, default)` | 枚举，按 `Enum.name` 序列化 |
| `configList` / `configMap` | 列表 / 映射，元素类型用 `Codec` 指定 |
| `config(name, default, codec)` / `ConfigItem(name, default, ConfigSerde.of(...))` | 自定义结构（自己写 `Codec` / 用 `ConfigSerde.of`） |

### 2.2 本仓新增（`config/item/`）

| 构造器 | 说明 |
|---|---|
| `configKeybind(name, defaultValue: Keybind)` | 一段按键组合（配置项自身可变，见 [06 输入与快捷键](06-输入与快捷键.md)） |
| `configKeybind(name, vararg defaultKeys, setting = KeybindSetting(), action = {})` | 同一个键位配置项 + 直接给按下时动作 |
| `configToggleKeybind(name, defaultEnabled, defaultValue: Keybind, onSwitch = ...)` | 开关式快捷键：`enabled` 与 `keybind` 一起存；**默认 `onSwitch` 会弹一条「组 → 配置名 : 开/关」的 Toast**（tag 取配置路径，连按只刷新同一条） |
| `configToggleKeybind(name, defaultEnabled, vararg defaultKeys, setting, onSwitch)` | 同上，直接用按键声明 |
| `configKeyCode(name, default)` | 单个按键码（不是组合键） |
| `configVector2i/2f/2d`、`configVector3i/3f/3d`（`name, default, min, max`） | JOML 向量，带范围（`Config.range` 可读回） |
| `configEnum(name, default, codec)` | 与 nebula 同名同形，但**允许指定枚举自己的 `Codec`**（要写小写字面量如 `"cubic"` 时用） |
| `configStringPair(name, default)` / `configPair(name, default, serdeA, serdeB)` | 键值对 |
| `configPairList(name, default, serdeA, serdeB)` | 键值对列表（界面按列表 + 编辑弹窗呈现） |

## 3. 读取、观测与默认值

```kotlin
// 直接读
val scaleNow = YourModConfigs.Gui.scale

// 派生一个 Codec 型复杂项
private val easingCustomConfig =
    addConfig(ConfigItem("easing_custom", CubicBezier.Standard, ConfigSerde.of(CubicBezier)))

// 观测：值变化时回调（返回可 dispose 的句柄）
YourModConfigs.Gui.scale.observe { cfg -> ScreenAnimationDefaults.slideFraction = cfg.getValue() }

// 默认值 / 重置
cfg.isDefault()        // 是否等于默认值（界面据此禁用"重置"按钮）
cfg.resetDefault()     // 恢复默认值
```

约定：**需要"写到运行时"的项在 `init()` 与 `observe` 两处都灌一次**（`init` 负责启动即生效，
`observe` 负责运行期改动），仓库里的 `IGConfig` 就是这么写的：

```kotlin
val disableWorldRender by configBoolean("disable_world_render", false)
    .apply { observe { ComposeScreenDefaults.disableWorldRenderByDefault = it.getValue() } }

override fun init() {
    super.init()
    ComposeScreenDefaults.disableWorldRenderByDefault = disableWorldRender
}
```

## 4. 生命周期

注册到处理器后（`register`）由处理器负责：

| 时机 | 行为 |
|---|---|
| `ClientLifecycleEvent.Starting` | 逐个 `manager.init()`（构造配置项树）→ `load()`（读文件）；**读失败会 `forceSave()` 重写** |
| `ClientLifecycleEvent.OpenGameMenu` | `savable()` 的项异步保存（`asyncSave()`） |
| `ClientLifecycleEvent.Stopping` | 同步 `save()` |

手动控制（不用处理器或做测试时）：

```kotlin
YourModConfigs.init()        // 初始化配置树
YourModConfigs.load()        // 从文件加载
YourModConfigs.save()        // 需要时写回
YourModConfigs.forceSave()   // 强制写回（忽略"脏"判断）
YourModConfigs.savable()     // 是否有变更
YourModConfigs.asyncSave()   // 异步保存，返回 Deferred
```

## 5. 序列化与文案键

- 复杂类型用 `Codec` 描述：`ConfigSerde.of(CubicBezier)`、`ConfigSerde.of(codec)`，
  或 `addConfig(ConfigItem("key", default, serde))`。列表 / 映射元素类型同样传 `Codec`。
- 每个配置节点自动得到**翻译键**：根为 `<modid>.<config>` 或 `<modid>.config.<name>`，
  下面按 `path` 拼接；注释键是同名 + `.comment`。对应语言文件里写：

```jsonc
"your_mod_id.config.gui.title": "标题",
"your_mod_id.config.gui.title.comment": "显示在界面上的标题",
```

界面（[03 配置界面](03-配置界面.md)）与 tooltip 都按这套键取文案。
