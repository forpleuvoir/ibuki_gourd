# 09 覆盖层与提示

这章解决：**画在原版界面 / HUD 之上的常驻内容**（覆盖层）、**操作反馈**（Toast）、**悬停提示**（Tooltip）。

## 1. 全局覆盖层

覆盖层是一块**不隶属任何屏幕**的常驻内容区，画在原版 HUD、原版界面、Compose 屏幕之上
（`Toast` 就是它的一个注册条目）。

```kotlin
val handle = OverlayService.register(
    key = "yourmod:hud",
    present = { YourModConfigs.Gui.showHud },       // 返回 false 时这一条连组合都不参与
) {
    // 内容作用域是铺满窗口的 BoxScope，位置自己 align
    Box(Modifier.fillMaxSize()) {
        Text("fps: ...", modifier = Modifier.align(Alignment.TopStart).padding(4.dp))
    }
}

// 不再需要时
handle.unregister()
```

| API | 说明 |
|---|---|
| `register(key: Any, present: () -> Boolean = { true }, content: @Composable BoxScope.() -> Unit): OverlayHandle` | 按 key 注册；**同 key 重复注册会替换旧条目**（旧句柄随之失效） |
| `register(present = ..., content = ...): OverlayHandle` | 自动分配 key，多个互不干扰 |
| `registerFrameListener(callback: (Duration) -> Unit): OverlayHandle` | 每帧回调（参数为本帧时长，长停顿已截断），用来推进你自己的计时 |
| `unregister(key): Boolean` / `contains(key): Boolean` / `clear()` | 注销 / 查询 / 清空（`clear` 只清条目，不含帧回调） |

行为约定：

- 条目表是 **snapshot state，可任意线程注册 / 注销**，变化在下一次场景组合时生效；
  条目按注册顺序组合，先注册的在底层。
- 覆盖层**只转发鼠标移动**（够做悬停高亮），不转发点击 / 滚轮 —— 需要交互的内容请做成屏幕或弹层。
- 宿主 `OverlayHost` 由 `mixin/client/GuiRendererOverlayMixin.java` 挂在 `GuiRenderer.render` 的 TAIL
  每帧驱动，**没有条目参与渲染时整帧跳过**（不组合、不绘制）。
- 场景根复用 `SokitsuScreenRoot`，所以覆盖层与屏幕**同档缩放**（同一 `SokitsuScreenDefaults.resolver`）：
  窗口变小会一起收缩，素材倍率也跟着走。**在条目内再套一层主题换配色时，记得传
  `pixelScale = LocalSokitsuPixelScale.current`**，否则会把分档覆盖回主题缺省值。
- 覆盖层的渲染器**不注册**到 `ComposeGuiRenderer.active`（那是屏幕占用的单值槽位），
  两者互不干扰；调用 `OverlayHost.onFrame()` 只允许在渲染线程。

## 2. Toast（操作反馈）

```kotlin
// 带标准外观（面板 + 倒计时条）
ToastHandler.showContent { Text("已保存") }

// 完全自定义外观
ToastHandler.show { Row { Icon(Icons.Checked); Spacer(Modifier.width(4.dp)); Text("已保存") } }
```

```kotlin
fun ToastHandler.showContent(
    duration: Duration = IGConfig.Gui.Toast.duration,   // <= 0 表示不自动消失
    strategy: ToastStrategy = ToastStrategy.ReplaceAll,
    animation: ToastAnimation? = null,                  // null = 主题 meta 的默认进出场
    modifier: Modifier = Modifier,
    contentAlignment: Alignment = Alignment.Center,
    propagateMinConstraints: Boolean = true,
    content: @Composable BoxScope.() -> Unit,
)

fun ToastHandler.show(duration = ..., strategy = ..., animation = null, content: @Composable () -> Unit)
fun ToastHandler.dismissAll()
```

- **冲突策略** `ToastStrategy`：`ReplaceAll`（替换全部，缺省）/ `Refresh`（有则重播倒计时）/
  `Enqueue`（排队，等可见数不足上限时出队）/ `Tagged.Refresh` / `Tagged.Replace` / `Tagged.Drop`
  （同一 `tag` 内按策略处理，`Tagged` 都带 `fallback`）。
- 全局常驻：不依赖任何屏幕，原版界面、无界面（HUD）、Compose 屏幕之上都能看到。
- 配置项（`IGConfig.Gui.Toast`）：`duration`（默认时长，只作用于**未显式传**的调用）、
  `adaptive_color_scheme`（是否跟随界面配色）、`light_mode`（不跟随时用自己的亮/暗）、
  `max_visible`（同屏上限）、`offset`（窗口比例落点，`x` 0~1、`y` 为面板中心高度比例）。
- 主题 meta 键为 `toast`（面板素材 / 配色 / 进出场动画），资源包可覆盖。

## 3. Tooltip（悬停提示）

```kotlin
Text("悬停我", modifier = Modifier.tooltip { Text("提示内容") })

// 钉住：跳过悬停延迟、忽略移出（做按键捕获一类的实时气泡用）
Modifier.tooltip(pinned = inputting) { Text("按下的键：...") }
```

```kotlin
fun Modifier.tooltip(
    interactionSource: MutableInteractionSource? = null,
    position: AnchorPosition = AnchorPosition.Above,
    delay: Duration = TooltipDefaults.delay,
    exitDuration: Duration = TooltipDefaults.exitDuration,
    color: Color = Color.Unspecified,
    contentColor: Color = Color.Unspecified,
    textStyle: TextStyle = LocalTextStyle.current,
    pinned: Boolean = false,
    content: @Composable () -> Unit,
): Modifier

fun Modifier.basicTooltip(          // 只要气泡体、内容与定位全自己给
    interactionSource: MutableInteractionSource? = null,
    delay: Duration,
    positionProvider: (anchorBounds: () -> Rect) -> PopupPositionProvider,
    exitDuration: Duration,
    pinned: Boolean = false,
    properties: PopupProperties = PopupProperties(focusable = false),
    content: @Composable TooltipScope.() -> Unit,
): Modifier
```

- 提示层经场景根的 `LocalPopupHost` 注册，**不产生布局节点**（不会把父级 `Row` / `Column` 的
  子项计数搞乱，可以安全地挂在任意组件上）。
- 配色 / 面板 / 字号走 `TooltipTheme` 与主题槽位；下拉菜单（`DropdownMenu`）复用同一套气泡体素材。
