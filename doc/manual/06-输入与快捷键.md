# 06 输入与快捷键

这章解决：**给功能绑按键**（含组合键、触发模式、环境限定、穿透），以及**做快捷键编辑界面**。

输入系统的核心是 `Keybind`（一段按键组合 + 触发设置 + 动作）与 `InputHandler`（注册表 + 冲突检测）。
键盘 / 鼠标事件由 mixin 喂进 `InputHandler`，`Keybind` 在 tick 里判定触发。

## 1. 快速开始

```kotlin
import moe.forpleuvoir.ibukigourd.input.InputHandler
import moe.forpleuvoir.ibukigourd.input.Keybind
import moe.forpleuvoir.ibukigourd.input.Keyboard
import moe.forpleuvoir.ibukigourd.ui.sokitsu.Text
import moe.forpleuvoir.ibukigourd.ui.sokitsu.toast.ToastHandler

val openKey = Keybind(Keyboard.RIGHT_SHIFT) {
    // action：接收者是 Keybind 自身
    ToastHandler.showContent { Text("pressed") }
}

// 注册进输入系统（返回句柄，可 unregister）
val handle = InputHandler.register(openKey)
```

要用**配置项**管理（这样它会出现在配置界面里，可改键）：

```kotlin
import moe.forpleuvoir.ibukigourd.config.item.configKeybind
import moe.forpleuvoir.nebula.config.ConfigGroup

object Gui : ConfigGroup("gui") {
    val openKey by configKeybind("open_key", Keyboard.RIGHT_SHIFT) {
        /* 按下时执行 */
    }
}
```

## 2. 关键 API

### `Keybind`（`input/Keybind.kt`）

```kotlin
class Keybind(
    vararg keyCodes: KeyCode,
    private val defaultSetting: KeybindSetting = KeybindSetting(),
    action: Keybind.() -> Unit = {},
)
```

| 成员 | 说明 |
|---|---|
| `keys: List<KeyCode>` | 当前按键组合（构造时去重；可被捕获 / `setKey` / `setFrom` 改写） |
| `var action: Keybind.() -> Unit` | 触发时执行；接收者是 `Keybind` |
| `var name: Text` | 展示名；不设时自动拼 `keys.joinToString(" + ") { it.keyName }` |
| `var setting: KeybindSetting` | 触发设置（`private set`，改它用 `setFrom(setting)`） |
| `setKey(vararg keyCodes: KeyCode): Boolean` | 直接改写按键组合（同样去重），有变化时返回 `true`；捕获 UI 就是走它 |
| `setFrom(target: Keybind, action: Boolean = true): Boolean` | 从另一份绑定复制按键（与设置），`action = false` 时不覆盖动作；返回是否变化 |
| `setFrom(setting: KeybindSetting): Boolean` | 换触发设置 |
| `resetState()` | 清掉"当前按下"状态与长按计时 |
| `observe { }` | 值变化回调（nebula `Observable`），返回可 `dispose` 的句柄 |
| `isDefault()` / `resetDefault()` | 是否等于构造时的默认值 / 恢复默认 |

### `KeybindSetting`（`input/KeybindSetting.kt`）

```kotlin
data class KeybindSetting(
    val env: KeyEnvironment = KeyEnvironment.InGame,   // 生效环境
    val trigger: KeyTriggerTiming = KeyTriggerTiming.Press,  // 触发模式
    val passthrough: Boolean = false,                  // 触发后是否放行这次输入（交给原版继续处理）
    val strict: Boolean = true,                        // 严格模式：只认完全一致的组合
    val longPressThreshold: Int = 20,                  // 长按阈值（客户端游戏刻）
    val repeatInterval: Int = 5,                       // 重复触发间隔（客户端游戏刻）
)
```

构造时要求 `longPressThreshold > 0` 且 `repeatInterval > 0`（`require`）；快捷键设置界面给前者的输入范围是
`1..200`、后者是 `1..100`。

| `KeyTriggerTiming` | 语义 |
|---|---|
| `Press` | 按下瞬间触发（仅一次，缺省） |
| `WhilePressed` | 按住期间持续触发（按 `repeatInterval`） |
| `LongPress` | 长按达成瞬间触发（仅一次，阈值 `longPressThreshold`） |
| `WhileLongPressed` | 长按期间持续触发 |
| `Release` | 松开时触发 |
| `PressAndRelease` | 按下与松开各触发一次 |

| `KeyEnvironment` | 语义 |
|---|---|
| `InGame` | 只在没有界面时（缺省） |
| `InGui` | 只在有界面时 |
| `Any` | 都生效 |

`currentEnv()` 返回当前环境（`mc.gui.screen() != null` → `InGui`，否则 `InGame`）。

### `KeyCode` / `Keyboard` / `MouseButton`

- `KeyCode` 是 `sealed interface`，实现只有两个枚举：`Keyboard`（键盘，含 `Keyboard.UNKNOWN`）与 `MouseButton`（鼠标键）。
- 每个 `KeyCode` 有 `code: Int`（GLFW 码）、`keyName: String`（本地化名）、`keyNameText: MutableText`、
  `translationKey: String`（原版按键翻译键，也是它的序列化形式）。
- `KeyCode.fromCode(code: Int): KeyCode` 按 GLFW 码反查，未知码回落 `Keyboard.UNKNOWN`。
- `KeyCode.ALL_KEYS`：全部键盘 + 鼠标键码，做"通配捕获"时用。
- `MouseCursor`（`input/MouseCursor.kt`）**不是** `KeyCode`：它是 `@JvmInline value class` 包一个 GLFW 标准光标值，
  用 `ArrowCursor` / `IbeamCursor` / `PointingHandCursor` 之类的常量调 `apply()` 换光标，`MouseCursor.reset()` 恢复箭头。
- `Keyboard.isToggle(keyCode)`：判断这个键是不是 `Enter` / `Space` / `KP_ENTER`。

### `InputHandler`（`input/InputHandler.kt`，单例 `object`）

| API | 说明 |
|---|---|
| `register(keybind: Keybind): Disposable` | 注册；同一实例重复注册会 `require` 失败（按引用判重） |
| `register(vararg keyCodes, defaultSetting, action): Disposable` | 便捷重载，内部造 `Keybind` |
| `unregister(keybind): Boolean` | 注销（同时断开注册时建立的变更监听） |
| `detectKeyConflicts(keyBind): Sequence<Keybind>` | 冲突检测：按键组合**按相同顺序**完全一致（`keys.exactMatch`）、且两边 `env` 不互斥的绑定 |
| `pressedKeys: Set<KeyCode>` | 当前按下的键码 |
| `wasKeyPressed(keyCode: KeyCode): Boolean` | 该键是否处于按下状态 |
| `wasKeyPressed(vararg keyCode: KeyCode): Boolean` | 当前按下的键是否**按相同顺序**完全等于这一组（逐位比较，顺序敏感） |
| `currentPressKeyCode` / `beforePressKeyCode: List<KeyCode>` | 本次 / 上次事件后的按下集合（按键判定内部用） |
| `releaseAll()` | 清空所有绑定的按下状态与按下集合（界面切换一类场景用） |
| `keybindVersion: Long` | 绑定表的版本号（注册 / 注销 / 变更都会推进；UI 靠它重组刷新，如 `Keybind.hoverText()`） |

`InputHandler.Disposable.dispose()` 即注销，配合 `ClientLifecycleEvent` 一类时机使用。

## 3. 配置项入口（`config/item/ConfigKeyBind.kt`）

| 构造器 | 用途 |
|---|---|
| `configKeybind(name, defaultValue: Keybind)` | 以现成的 `Keybind` 声明（内部复制一份作为当前值） |
| `configKeybind(name, vararg defaultKeys, setting = KeybindSetting(), action: Keybind.() -> Unit)` | 用按键 + 动作声明；`action` 没有默认值，必须给 |
| `configToggleKeybind(name, defaultEnabled, defaultValue: Keybind, onSwitch = { showSwitchToast() })` | 开关 + 组合键：`enabled` 与 `keybind` 一起存；**默认 `onSwitch` 弹一条「组 → 配置名 : 开/关」的 Toast**（tag 取配置路径，连按只刷新同一条） |
| `configToggleKeybind(name, defaultEnabled, vararg defaultKeys, setting = KeybindSetting(), onSwitch = { showSwitchToast() })` | 同上，用按键声明；没有 `action` 参数（动作固定为「切换开关 + `onSwitch`」） |
| `configKeyCode(name, defaultValue: KeyCode)` | 单个按键，如滚轮倍率 Ⅰ/Ⅱ/Ⅲ 的触发键 |

两个 `configKeybind` 与 `configToggleKeybind` 都会在配置项 `init()` 时把当前 `Keybind` 注册进 `InputHandler`，
并把它的 `name` 设成「组 → 配置名」，**不需要**再自己注册。`configToggleKeybind` 的值类型是 `ToggleKeybind`，
配置项自身暴露 `enabled` / `keybind` 与 `toggle()`。

`IGConfig.Gui` 里有两个内置的 `configKeyCode`：`quickActionKeyCode`（缺省左 `Shift`，按住时「删除确认」一类操作
跳过二次确认）与 `hideActionKeyCode`（缺省左 `Alt`，按住时收起浮动按钮一类入口）；`ui/util/InputState.kt` 的
`isQuickAction` / `isHideAction` 与 `rememberQuickActionState()` / `rememberHideActionState()` 就是读这两个配置项。

## 4. 快捷键编辑界面（`ui/keybind/KeySetter.kt`，非 sokitsu 包）

| 组件 | 签名要点 | 用途 |
|---|---|---|
| `KeyCodeSetButton` | `(value: KeyCode, onValueChange: (KeyCode) -> Unit, modifier, enabled)` | 单键捕获：按下任意键即写入（只认最后按下的那一个），`Esc` / `Ctrl+Backspace` 取消 |
| `KeybindSetButton` | `(keybind: Keybind, onValueChange: (Keybind) -> Unit = {}, modifier, enabled)` | 组合键捕获：**松开全部按键才写入**，`Esc` / `Ctrl+Backspace` 清空；与其它绑定冲突时按钮换主题 `error` 配色 |
| `KeybindSettingSetButton` | `(keybindSetting: KeybindSetting, onValueChange, modifier, enabled, iconScale = 3, contentPadding)` | 齿轮按钮：弹扩展设置（确认后把整份 `KeybindSetting` 交回） |
| `KeybindSettingColumn` | `(keybindSetting, onValueChange, modifier)` | 扩展设置本体：穿透 / 严格 / 环境 / 触发模式 / 长按阈值 / 重复间隔（两个数值项只在对应触发模式下出现：长按类显示阈值、按住类显示间隔） |
| `Keybind.hoverText(): MutableText` | `@Composable` 扩展 | 悬浮提示：按键组合 + 冲突列表（读 `InputHandler.keybindVersion`） |

捕获的行为细节（自己写捕获 UI 时会用到）：

- 捕获是**事件驱动**的（`ui/util/InputState.kt` 的 `rememberKeyCapture`），不逐帧轮询、不在组合期写状态。
- 捕获期间在回调里 `cancel()` 掉原版的键盘 / 鼠标事件，**连按住的 `GLFW_REPEAT` 一起吞掉**。
- 捕获气泡用 `Modifier.tooltip(pinned = true)` 钉住：跳过悬停延迟、忽略移出、弹层不因外部点击关闭。
- 按下集合必须是 `LinkedHashSet`（`MutableList` 的 `add` 恒为 `true`，按住重复会重复入列、释放一次删不净）。

## 5. 注意事项

- **`InputHandler.register` 不负责注销**：注册返回 `InputHandler.Disposable`，模块卸载 / 关闭界面时要自己 `dispose()`。
- **`Keybind` 的默认值语义**：构造时给的是 `defaultSetting` 与初始按键；`isDefault()` / `resetDefault()` 都对照它。
- **`passthrough` 决定这次输入要不要放行给原版**：所有已注册的快捷键都会收到这次输入（判定与触发不受它影响），
  `false`（缺省）时触发方会取消原版的键盘 / 鼠标处理；要让原版也拿到这次输入（例如某个键本身还有原版绑定）才开 `true`。
- **`strict = true`**（缺省）要求组合完全一致：判定是 `keys == currentPressKeyCode` 的 **List 相等**，
  所以按键的**书写顺序要与按下顺序一致**（`Keybind(Keyboard.I, Keyboard.G)` 要按 I 再按 G）；
  想"包含即触发"用 `strict = false`（只要求当前按下的键包含绑定里的键，与顺序无关）。
- **`WhilePressed` 类触发依赖 `repeatInterval`**，间隔单位是**客户端游戏刻**（20 tick = 1 秒）。
- **`configToggleKeybind` 的默认 Toast 会被自定义 `onSwitch` 取代**：传了自己的 `onSwitch` 就不会再弹。
- **键码与按键名的翻译用词**：`keybind` → "快捷键"，`keycode` → "按键"（见 [12 常见问题](12-常见问题.md)）。
