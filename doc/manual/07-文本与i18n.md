# 07 文本与 i18n

定位：IbukiGourd 把 MC 的 `Component` 包了三件东西 —— `buildText` DSL 造富文本、`&{...}` 内联样式字符串、`IGLang` 统一登记 i18n 键。

## 快速开始

```kotlin
import moe.forpleuvoir.ibukigourd.lang.MiscLang
import moe.forpleuvoir.ibukigourd.text.*
import moe.forpleuvoir.ibukigourd.ui.sokitsu.Text

// 1) DSL 造富文本
val tip: MutableText = buildText {
    literal("已复制 ")
    translatable("item.minecraft.slime_ball") { style { color("#7CFC00") } }
    newLine()
    literal(42) { style { bold() } }
}

// 2) 内联样式字符串（返回 MutableText）
val warn: MutableText = InlineStyleText("&{#ff5555,b}警告&{!b}: 普通文本")

// 3) 取 i18n 文案（本身就是 MutableText，可继续 .withColor(...)）
val confirm: MutableText = MiscLang.confirm

// 4) 塞进 sokitsu 组件：走 Component 重载
Text(MiscLang.copy)
```

## 关键 API

| API | 签名 | 说明 |
|---|---|---|
| `buildText` | `buildText(content: TextBuilder.() -> Unit): MutableComponent` | DSL 入口（`text/TextDSL.kt`） |
| `TextBuilder.literal` | `literal(content: Any, scope: LiteralBuilder.() -> Unit = {})` | 追加字面量，`toString()` 后写入 |
| `TextBuilder.translatable` | `translatable(key: String, vararg params: Any, scope: TranslatableBuilder.() -> Unit = {})` | 另有带 `fallback` 的重载与纯 scope 重载 |
| `Literal` / `Translatable` | `Literal(content: String = "")`、`Translatable(key: String, fallback: String? = null, vararg args: Any): MutableText` | 单个组件的快捷构造（`text/TextExtensions.kt`） |
| `Texts` | `Texts.literal / translatable / empty / keybind / inlineStyle` | `object` 门面；`Texts.keybind(key)` 产出原版按键占位 |
| 类型别名 | `typealias Text = Component`、`typealias MutableText = MutableComponent` | 均在 `text` 包 |
| `InlineStyleText` | `InlineStyleText(exp: String): MutableText` | 解析 `&{...}` 内联样式 |
| `InlineStyleTextParser.inline` | `inline(text: Text): String` | 反向序列化回 `&{...}` 字符串 |
| 追加 | `appendLiteral(String)` / `appendTranslate(key, fallback?, vararg args)` / `appendLTRArrow()` / `appendRTLArrow()` / `appendNewLine()` / `append { }` | `text/Texts.kt` |
| 样式 | `MutableText.style { StyleBuilder.() -> Unit }` / `withColor(Color)` / `withShadowColor(Color)` | `Color` 是 nebula 的 `moe.forpleuvoir.nebula.common.color.Color` |
| `StyleBuilder` | `color(Color?/Int?/String?)`、`shadowColor(...)`、`bold/italic/underlined/strikethrough/obfuscated(Boolean?)`、`clickEvent`、`hover(ItemStack/Entity/EntityTooltipInfo/Component)`、`insertion`、`font` | `text/style/StyleDSL.kt` |
| `flat` | `MutableComponent.flat(): List<Text>` | 把嵌套 siblings 拍平成单层列表 |
| 枚举文案 | `translateText` / `translateKey` / `translateComment` / `translateCommentKey` | `translateKey == "enum.${javaClass.name}.$name"` |
| 客户端排版 | `String.wrapToLines(maxWidth)`、`MutableComponent.wrapToTextLines(maxWidth)`、`Iterable<String>.size(spacing)` / `totalHeight(spacing)`、`String?.size / width / height` | `text/ClientTextExtensions.kt`、`text/TextSizeSupplier.kt`；依赖 `mc.font` |
| `IGLang` | 子对象 `Misc` / `Color` / `ConfigWrapper` / `Input` / `Theme` | i18n 键命名空间中心 |
| `TranslationRecorder` | `record(key)` / `addFilter { }` / `dump(path: Path)` / `categorizer` | 语言键导出（`lang/TranslationRecorder.kt`） |

## 常见用法

### 1. 内联样式字符串

`&{expr,expr,...}` 声明一组修饰符，**作用于其后所有字面量，直到下一个 `&{`**（这是最容易踩的一点）。

```kotlin
InlineStyleText("&{#ff5555,b}红色加粗&{!b} 仅红色 &{#none} 恢复默认")
```

| 表达式 | 效果 |
|---|---|
| `#RRGGBB` / `#RRGGBB->#RRGGBB` | 主色 / 渐变 |
| `s#RRGGBB` | 阴影色（`s` 前缀；`s#null` 清空） |
| `[h s v]` / `[h s v]->[h s v]` | HSV 颜色 / 渐变，如 `[0 100 100]` |
| `b` `i` `l` `s` `o` `r` | 加粗 / 斜体 / 下划线 / 删除线 / 乱码 / 重置（别名 `bold` `italic` `underline` …） |
| `!b` / `?b` | 显式关闭 / 置空（继承） |
| `$a` `$l` … | 原版格式码（前缀 `$`，两位） |
| `c:run_command=>/say hi` | 点击事件，动作 `open_url/open_file/run_command/suggest_command/change_page/copy_to_clipboard` |
| `h=>...` / `h=>null` | 悬停文本（内部不允许再嵌事件修饰符）/ 清空 |
| `ts=>键名` / `kb=>键名` | 换成 Translatable / Keybind 内容 |

### 2. 配置项的翻译键

`config/ConfigExtensions.kt` 从配置树路径推导键，命名规则为 `<modId>.config[.<manager 名>].<配置路径>`，注释键统一加 `.comment`：

```kotlin
val key = configNode.translationKey          // 如 ibukigourd.config.gui.theme.mode
val commentKey = configNode.translateCommentKey  // 上面 + ".comment"
val text = configNode.translateText          // 可直接铺到界面上
val all = IGConfig.exportTranslateKeys(onlyMissing = true)  // 批量导出
```

### 3. 导出待翻译的键（开发期）

`common/src/devOnly` 的 `igtest config_keys` 指令演示了 `TranslationRecorder` 的用法：设置 `categorizer` 决定落盘的 `<category>.json` 文件名，`addFilter { true }` 放行所有键，`dump(path)` 写出 JSON（`keepExisting = false` 时所有 value 都是空串，只列键）。

```kotlin
val recorder = TranslationRecorder(false, keepExisting = true)
recorder.categorizer = { "config" }
recorder.addFilter { true }
IGConfig.exportTranslateKeys().forEach(recorder::record)
recorder.dump(Path("../../../common/src/devOnly/lang"))
```

### 4. 在自定义宽度里排版

```kotlin
val lines: List<Text> = someComponent.wrapToTextLines(maxWidth = 120f)
val height = lines.totalHeight(spacing = 2f)
```

## 注意事项

- **语言键命名规则**（从现有 `assets/ibukigourd/lang/*.json` 反推）：`<modid>.<section>.<key>`。现有 section：`misc` / `color` / `config_wrapper` / `input` / `theme`（来自 `IGLang` 子对象）、`config`（配置树）；枚举走 `enum.<枚举类全名>.<常量名>` 与 `.comment`。新增文案登记到 `IGLang` 子对象，资源文件放 `common/src/main/resources/assets/ibukigourd/lang/<locale>.json`。
- **`ibukigourd.selector.*` 目前是孤儿键**：`selector.expand_style` / `selector.auto_max_items` 系列只在 `en_us` / `zh_cn` 里有，Kotlin 侧**零引用**（没有对应的配置组或 `*Lang` 对象）；要么给它落地对应的配置项，要么直接删。
- **`#xxx` 是伪键**：`"#color"`、`"#config"` 这类键只作为语言文件里的分节标记（`#<section>` 放在该节首行），Minecraft 不会解析出任何语义，不要拿它当真实键引用。
- **各 `*Lang` 的 `lang(...)` 辅助函数是 `internal`**：消费方只能用已定义的属性，不能自己拼 `<modid>.<section>.<key>`；自己模组的文案请自带自己的 `object` + 自己的 lang 文件。
- **`textWidthSupplier` 与 `TextSizeSupplier` 的 `size/width/height` 依赖 `mc.font`**：`wrapToLines` / `wrapToTextLines` / `String.width` 等都是客户端专用，服务端逻辑里不要调用。
- **两个 `MutableComponent.style { }` 同名**：`text.Texts.kt` 与 `text.style.StyleDSL.kt` 各定义了一个签名相同的扩展，同一文件里同时 `import moe.forpleuvoir.ibukigourd.text.*` 和 `import moe.forpleuvoir.ibukigourd.text.style.*` 会撞名 —— 只导入实际需要的那个。
- **`withColor` 收 nebula 的 `Color`**，不是 Compose 的 `androidx.compose.ui.graphics.Color`；两者互转用 `util/ColorConvert.kt` 的 `toComposeColor()` / `toNebulaColor()`。
- **`translatable(key, fallback, vararg params)` 会 `toString()` 参数**：传 `Component` 时拿到的是类的 `toString()`，要嵌组件请用 `append(...)`。
- **`TranslationRecorder.dump` 每个 category 覆盖写一个文件**：`keepExisting = false` 时 value 恒为空串，别拿它当"同步语言文件"用；`dump` 目标目录会被直接创建。
- **`igtest` 只在 `devOnly` 源集**：它 dump 到 `common/src/devOnly/lang`，该路径已进 `.gitignore`。
- **翻译用词**（zh_CN）：`keybind` → **快捷键**；单纯的按键码 `keycode` → **按键**。
